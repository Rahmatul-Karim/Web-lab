# Pokémon Card Explorer

A simple Pokémon search web application built using HTML, CSS, JavaScript, and the public PokéAPI.

## Project Description

Pokémon Card Explorer allows users to search for a Pokémon and view its information in a card-style layout.

The application gets Pokémon data from the PokéAPI and displays the information dynamically on the webpage.

## Features

- Search Pokémon by name
- Fetch Pokémon data using PokéAPI
- Show loading state while searching
- Show an error message for invalid Pokémon names
- Display Pokémon name and Pokédex ID
- Display official Pokémon artwork
- Display Pokémon types
- Display height and weight
- Display Pokémon abilities
- Display all six base stats
- Show stat bars based on the Pokémon's stats
- Quick search buttons for popular Pokémon
- Different card colors for different Pokémon types
- Responsive design for smaller screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- PokéAPI

## API Used

This project uses the public PokéAPI.

API endpoint:

https://pokeapi.co/api/v2/pokemon/{name}

For example:

https://pokeapi.co/api/v2/pokemon/pikachu
